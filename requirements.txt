# PSS on LayoutXLM — modernized dependency stack.

# Core versions are chosen to be mutually compatible:
#   torch 2.6  <->  torchvision 0.21  <->  transformers 4.53  <->  lightning 2.5
# Pick the CUDA build of torch/torchvision that matches your machine, e.g.:
#   pip install torch==2.6.0 torchvision==0.21.0 \
#       --extra-index-url https://download.pytorch.org/whl/cu124
# (swap cu124 for cu118 / cu126 as appropriate; omit for the CPU build).
